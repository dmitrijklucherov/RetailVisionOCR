##        12.09.26
Мой личный бот аналитик для ВК и ВБ

Скрипт на Python для автоматического сбора данных с ВБ, сохранения их в базу PostgreSQL и упрааление через сообщение группы ВК

## Файлы:

1. 'connect_vk_bot.py' - Сетевой блок. Работает на Long Poll, слушает сообщения в группе ВК и запускает команды.
2. 'data_base.py' - Блок управления БД. Автоматическое создание таблиц и запись строк.
3. 'parser.py' - Блок парсера. Будет через Pandas чистить данные с ВБ и анализировать цену.

## Безопасность:

Токен и пароль от БД спрятаны в скрытый файл '.env'. Через настроенный '.gitignore' защитил их от улетания в интернет, что бы на GitHub летел толко код без моих данных.
